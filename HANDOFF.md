## Заметки

- Локально: `npm run dev:server` (API :8787, база `./data/academy.sqlite3`) + `npm run dev` (Vite проксирует `/api`). Ключ первого запуска локально: `local-setup-key`. Демо: `npx tsx scripts/seed-demo.ts` (owner/owner123, сотрудники …/demo123).
- `npm run smoke` запускается через tsx, потому что читает банк вопросов финала из TS-файлов; при запущенном сервере.
- Ключи ответов финала сервер берёт из `src/data/final/`, на телефоны они не отправляются. Любая правка банка вопросов попадает на сервер при следующем деплое.
- Резервные копии: Render делает ежедневные снимки диска. Файл базы `/var/data/academy.sqlite3`.
- Один раз не появилась карточка с паролем после создания аккаунта (не воспроизвелось). Если пароль потерян — «Сбросить пароль» в списке аккаунтов.
