# Hotel Academy — платформа оценки сотрудников ресепшена

Дата: 2026-09-30. Статус: реализовано. Сервер проверен сквозным тестом `scripts/smoke-test.mjs` (87/87).

> **Изменение 2026-09-30:** бесплатного места в Supabase не нашлось, владелец выбрал Render Starter ($7/мес). Бэкенд перенесён с Supabase на собственный сервер Node + Express + SQLite на постоянном диске Render. Логика (права, пересдачи, подсчёт баллов финала, смешанный итог 70/30) перенесена один в один; разделы ниже описывают её в терминах таблиц, которые теперь живут в SQLite (`server/db.ts`).

## 1. Цель

Обучающий портал (15 модулей, тест знаний, общий PIN, прогресс в localStorage) превращён в систему, где:

1. Каждый сотрудник входит под личным аккаунтом, который создаёт владелец.
2. Сотрудник проходит обучение, тест знаний, тесты уровня английского и русского.
3. Владелец в админ-панели видит эффективность каждого сотрудника.
4. Владелец проводит финальный тест очно: сессия управляется с его экрана, сотрудники отвечают с телефонов.

## 2. Архитектура

- **Один сервис на Render (Starter)**: Node 24 + Express 5 отдаёт собранный SPA (React 19, Vite, HashRouter) и API `/api/*`.
- **Данные** — SQLite (better-sqlite3, WAL) в `DATA_DIR` на постоянном диске Render. Без смонтированного диска сервер в production не стартует.
- **Вход** — логин + пароль (scrypt), непрозрачный токен сессии в httpOnly cookie (Secure, SameSite=Lax), в базе хранится только sha256. «Запомнить устройство» — 30 дней со скользящим продлением, иначе 12 часов. Каждый изменяющий запрос обязан нести заголовок `x-academy: 1` (защита от подделки запросов с чужих сайтов). Подбор пароля ограничен: 10 ошибок за 15 минут.
- **Права** — проверяются на сервере в маршрутах (`requireUser`, `requireAdmin`); сотрудник видит только свои данные.
- **Реальное время** — Server-Sent Events `/api/final/stream`: один поток на вкладку, события `session`, `participants`, `answer` (только админам). Клиент считает событие поводом перечитать данные.
- **Первый запуск** — `SETUP_KEY` из переменных окружения, работает только пока нет ни одного администратора.

## 3. Данные

| Таблица | Назначение |
|---|---|
| `profiles` | Аккаунт: login (уникальный, `^[a-z0-9][a-z0-9._-]{2,31}$`), full_name, role, position, is_active |
| `module_progress` | Пройденные модули + результат «Проверь себя» (check_score/check_total) |
| `activity_log` | login, lesson_view (+durationSec), lesson_complete, test_start, test_finish, final_join |
| `test_attempts` | Все попытки (knowledge/english/russian/final): score, total, percent, level, details jsonb, writing jsonb, writing_rubric, writing_score 0–5, graded_by/at |
| `test_grants` | Разрешения на пересдачу языковых тестов (24 ч, одноразовые) |
| `final_sessions` | Живая сессия: status lobby/question/reveal/finished/cancelled, question_ids, current_index, current_question (без ключа), reveal, question_started_at/deadline_at (серверное время) |
| `final_question_keys` | Ключи вопросов финала — только админ и серверные функции |
| `final_participants` | Участники: display_name, last_seen_at (heartbeat), answered_count, score, rank |
| `final_answers` | Ответы, оцениваются на сервере; open_score 0–5 ставит админ |

Сводки считаются запросами сервера: обзор команды (`GET /api/admin/overview`) и статистика вопросов (`GET /api/admin/question-stats`). Ключи вопросов финала сервер берёт прямо из банка `src/data/final/` — на телефоны они не отправляются.

## 4. Аккаунты и вход

- Регистрация с сайта выключена. Edge Function `admin-users`: `status` (публично: есть ли админ), `bootstrap` (первый админ по секрету `ADMIN_BOOTSTRAP_KEY`, только пока админа нет, сравнение без утечки по времени), `create`, `reset_password`, `set_active`, `delete`. Функция сама проверяет токен и что вызывающий — активный админ.
- Логин отображается в email `login@academy.local`. Роль и поля профиля пишет функция сервисным ключом (GoTrue пишет app_metadata после INSERT, поэтому триггер создаёт только черновик профиля).
- Деактивация: бан в Auth + удаление refresh-токенов (`revoke_user_sessions`) + `is_active` во всех политиках записи. Нельзя деактивировать/удалить себя и последнего админа. Удаление — только после деактивации (в UI), каскадом удаляет результаты.
- «Запомнить устройство»: сессия в localStorage, иначе в sessionStorage. Перед каждым тестом блок «Вы: Имя (логин) — Не вы? Выйти» для общего ПК на стойке.
- Первый запуск: ссылка на странице входа ведёт на `/setup`, пока админа нет.

## 5. Тесты

### 5.1 Модули и тест знаний
- Модуль засчитывается после «Проверь себя» (4 вопроса модуля, 30 с на вопрос, мгновенная обратная связь, проход только при всех верных; просроченный вопрос = ошибка). Время чтения пишется при уходе со страницы (fetch keepalive).
- Тест знаний — режим assessment: 60 вопросов (по 4 на модуль), варианты перемешаны, 45 с на вопрос (не подтверждённый вовремя — неверный), уход со страницы обнуляет открытый вопрос (`details.timedOut`, `details.forfeited`), без обратной связи до конца, в конце процент и разбор по модулям без ключа. Пересдача не раньше чем через 24 ч (`KNOWLEDGE_RETAKE_HOURS`, сервер отвечает 403 `retake_too_soon`; админ освобождён). Проходной балл 90 %. Сертификат выдаётся не за тест знаний, а за финальный тест (см. 5.3).

### 5.2 Английский и русский (CEFR)
- Банк: 16 вопросов на уровень A1–C1 на язык (по 4 на грамматику, лексику, диалог, чтение), сложность — верхняя граница уровня, дистракторы «почти верные». Письменные задания: 11 на язык (A2–C1, не менее 2 на уровень).
- Один тест на 20 вопросов, 15 минут: по одному вопросу каждого навыка с каждого уровня A1–C1 (в приоритете невиденные ранее), от A1 к C1. Уровень засчитан при 3/4 верных и засчитанных всех уровнях ниже; итог — наивысший такой уровень, «A0» = ниже A1. Незавершённые попытки старого формата (version 1 в localStorage) отбрасываются.
- Письменная часть с A2: ответ гостю, 8 минут, объём по уровню (A2 40–80, B1 70–120, B2 100–160, C1 140–220 слов), вставка текста заблокирована (попытки считаются), оценка владельцем по 4 критериям (задача, тон, грамматика, лексика по 0/0.5/1 → 0–5).
- Первая попытка свободная; пересдача только по гранту владельца (триггер в БД). Состояние попытки хранится в localStorage — обновление страницы не теряет тест.
- Сигналы честности в details: фокус уходил со вкладки, медианное время ответа, переводчик страницы, устройство. В админке — янтарные флаги «проверить» (не автосбой).

### 5.3 Финальный тест (живая сессия)
- Банк: 45 сценарных вопросов с выбором и 12 открытых заданий с критериями оценки (два открытых — на английском и русском для очной сверки уровня).
- Создание: N вопросов с выбором (по умолчанию 30, распределены по модулям) + M открытых (по умолчанию 4), время 20 с / 90 с. Одна живая сессия за раз (уникальный индекс).
- Все переходы — RPC с проверкой ожидаемого состояния (`open_final_question`, `reveal_final_question`, `finish_final_session`, `cancel_final_session`): двойной клик или устаревшая вкладка ничего не ломают. Время вопроса — серверное; клиенты считают смещение через `server_now()`.
- Ответ — идемпотентный RPC `submit_final_answer`: проверяет участника, текущий вопрос и дедлайн (+1 с), считает баллы на сервере (100 за верный, +20 если в первой трети времени). Ключи ответов не попадают на телефоны.
- Экран ведущего восстанавливается после обновления; авто-показ ответа по дедлайну или когда ответили все активные участники (heartbeat 25 с).
- Итог: процент = правильные / заданные вопросы с выбором (пропуск = 0). После оценки открытых: 70 % выбор + 30 % открытые. Очки за скорость — только для таблицы лидеров.
- Сертификат: лучший финальный результат от 80 % (`CERTIFICATE_MIN_FINAL_PERCENT`) при полностью оценённых открытых ответах (`gradingStatus` ≠ pending). Обзор отдаёт `finalBestGraded`, статус «сертифицирован» считается от него.

## 6. Админ-панель

- **Обзор**: KPI, распределение уровней EN/RU, таблица сотрудников со статусом (не начал / учится / тесты сданы / сертифицирован), флаги внимания, поиск, сортировка, CSV.
- **Аккаунты**: создание с генерацией пароля и карточкой «передать сотруднику», редактирование, сброс пароля, деактивация, удаление.
- **Сотрудник**: обучение (даты, «Проверь себя», время чтения), тесты (разбор по модулям, уровни по ступеням, флаги честности, оценка письма, гранты на пересдачу, финал), лента активности.
- **Финальный тест**: создание сессии, история, результаты, оценка открытых ответов, статистика вопросов, CSV.
- **Вопросы**: % правильных по каждому вопросу, флаги «слишком сложно/проверьте ключ» и «слишком легко».
